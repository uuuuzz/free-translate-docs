隐私与数据处理

隐私政策

生效日期：2026 年 10 月 29 日 · 最近更新：2026 年 10 月 29 日

本政策由“免费翻译”浏览器扩展的维护者（GitHub 账号 uuuuzz，下称“我们”）提供，说明现有扩展及本政策网页如何处理信息。扩展用于网页正文、选中文字和可读取的视频字幕翻译。它是独立开发的产品，不代表 Google、腾讯云或其他模型服务商。

先了解这三点
  • 默认的“Chrome翻译”使用浏览器提供的本地翻译能力。

  • 当前扩展没有开发者运营的翻译代理后台，也没有广告或分析统计 SDK。设置、凭据和缓存主要保存在你的浏览器中。

1. 处理哪些信息

  • 翻译内容：你选择或允许翻译的网页正文、选中文字、可读取的字幕，以及为保持译文连贯性而使用的少量相邻字幕。自动正文扫描会跳过常见输入控件、表单和代码区域；普通网页文本或主动选中的内容仍可能包含个人或敏感信息。
  • 页面和播放信息：当前页面地址、站点来源、标题、视频标识、字幕轨道及播放时间，用于识别内容、应用网站偏好和同步字幕。扩展不调用浏览历史 API，也不建立上传给开发者的完整浏览历史档案。
  • 设置和凭据：选择的引擎和语言、网站翻译规则、显示设置、自定义接口地址与模型 ID、图标、你填写的 API Key 或访问令牌，以及本机字符预算。
  • 本机缓存和诊断：原文或译文缓存、缓存标识、用量计数、请求耗时、错误码、请求 ID 和时间。扩展自身的诊断不主动记录 API Key 或待译正文；功能缓存与诊断是不同的数据。

2. 本地与云端翻译

Chrome翻译

在浏览器支持相应能力且语言包就绪时，译文由设备上的浏览器翻译模型生成，扩展不会为这一路翻译把待译文字发送给开发者或云端模型接口。浏览器可能需要下载语言包；其自身的数据处理遵循浏览器提供方的说明。读取在线视频字幕仍可能访问原网站，因此本地翻译不代表整个扩展完全不联网。

云端模型与自定义接口

当你选择并启动云端翻译，或启用了某站点的自动翻译，扩展会向所选接口发送待译文本片段、源语言与目标语言、条目标识及必要的翻译指令；视频翻译可能包含少量相邻字幕。请求使用相应 API 凭据进行认证。

当前版本由浏览器直接请求所选服务，不经过我们运营的翻译代理服务器。服务商可接收到请求内容及正常网络连接所涉及的信息，例如 IP 地址、请求时间和客户端信息。扩展不把原站点的登录 Cookie 或整个浏览器历史作为模型翻译负载发送。

扩展不提供无字幕音视频的语音识别，也不为翻译上传音视频流。本地导入的字幕先在浏览器解析；如果随后使用云端翻译，其中需要翻译的文字可能被发送，原始音视频文件不会因此上传。

4. 数据保存在何处、保存多久

  • API Key：你填写的 Key 默认保存在扩展会话存储中，会在浏览器或扩展会话结束、重置时清除。勾选“在本机长期保存密钥”后，Key 会保存在本机扩展存储中，直到你删除或卸载扩展。长期保存不是加密保险箱。
  • 其他设置：模型、语言、网站规则及显示偏好等保存在本机扩展存储中。扩展不使用 Chrome 同步存储自动同步这些数据。
  • 内容缓存：持久字幕和云端译文缓存通常有 14 天的有效期，并受容量或条数限制；过期数据在后续读写或手动清理时剔除，不是到点即运行的删除服务。页面内临时字幕、导入内容和本地译文缓存会随页面关闭或重置释放。
  • 诊断与计数：保存在本机，用于显示最近连接状态和用量。清空译文缓存不会自动清空服务设置、Key 或用量记录。
  • 导出文件：你导出的 SRT、VTT 等文件由你保管，关闭或卸载扩展不会删除这些下载文件。

部分测试发行版包含开发者提供的有限共享模型授权。它们不是用户的个人 Key，也不代表无限免费额度；用户自行保存的 Key 优先使用。包内凭据封装不能保证安装者无法提取，实际访问范围和额度由服务商控制。

5. 为什么需要权限

  • storage：保存上述设置、凭据、缓存和本机状态。
  • activeTab 与 scripting：在用户操作或已授权的网站中运行随扩展打包的翻译逻辑。
  • contextMenus：提供右键翻译入口。
  • 原视频站点及模型接口域名权限：读取相应字幕、发送用户选择的翻译请求。
  • 可选 HTTP/HTTPS 网站权限：用于用户授权的其他网页、自动翻译网站或自定义接口。

网站权限本身不等于自动向模型上传所有网页。翻译是否执行取决于你的操作和保存的网站规则；视频站点的适配脚本可能预先读取或暂存页面已经收到的相关字幕响应。

6. 你的控制与删除方式

  • 选择 Chrome翻译、关闭翻译或将网站偏好改为“不自动翻译本站”，可以控制后续翻译。停止或取消请求不能保证撤回服务商已经收到的数据。
  • 在翻译服务设置中勾选“删除该服务已保存的密钥”并保存，可移除个人 Key。
  • “删除自定义模型”会清除该配置及保存的 Key，不删除远端模型。扩展保留不含接口、名称和 Key 的版本标记，防止旧结果恢复。
  • 使用“清空云端译文缓存”及视频面板中的字幕缓存清理功能，可分别清理对应缓存。恢复网页原文只是显示操作，不等于清空缓存。
  • 可以在 Chrome 的扩展管理中撤销网站访问权限或卸载扩展。卸载会清理扩展的本机存储；导出文件及服务商保留的数据需另外处理。

7. 用途限制与安全措施

我们将扩展处理的信息用于提供翻译、保存用户偏好、缓存、用量控制及必要的故障处理。我们不出售这些信息，不将其用于定向广告或信用评估，也不使用待译内容训练开发者自有模型。当前扩展没有广告 SDK、分析统计 SDK 或把翻译内容发送给开发者的遥测服务。

远程模型请求使用 HTTPS；用户配置的本机回环接口可以使用 HTTP。个人 Key 不显示在网页翻译浮层或扩展诊断中，内置测试授权只在扩展后台使用。所有客户端软件都存在风险，本机存储、包内凭据和第三方处理不能被描述为绝对安全。

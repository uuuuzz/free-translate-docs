Privacy and data handling

Privacy Policy

Effective: October 29, 2026 · Last updated: October 29, 2026

This policy is provided by the maintainer of the Free Translate browser extension (GitHub account uuuuzz, “we” or “us”). It describes the current extension and this policy website. The extension translates webpage text, selected text and accessible video captions. It is independently developed and is not an official product of Google, Tencent Cloud or another model provider.

Three things to know
  • The default “Chrome翻译” option uses the browser’s local translation capability.
  • Cloud translation sends the text to the selected service. Enabling automatic translation for a site also allows eligible content on that site to enter the translation flow automatically.
  • The current extension has no developer-operated translation proxy, advertising SDK or analytics SDK. Settings, credentials and caches are primarily stored in your browser.

1. Information the extension handles

  • Translation content: webpage text, selections and accessible captions that you choose or permit to translate, plus a small amount of adjacent caption text for context. Automatic webpage scanning excludes common input controls, forms and code areas. Ordinary page text and explicit selections may still contain personal or sensitive information.
  • Page and playback information: the current page address, site origin, title, video identifier, caption track and playback time, used to identify content, apply site preferences and synchronize captions. The extension does not call the browser history API or build a complete browsing-history profile for upload to the developer.
  • Settings and credentials: your selected engine and languages, site rules, display preferences, custom endpoints, model identifiers, icons, personal API keys or access tokens, and local character budgets.
  • Local caches and diagnostics: source-text or translation caches, cache identifiers, usage counts, request timing, error codes, request IDs and timestamps. The extension’s diagnostics do not intentionally record API keys or translation content. Functional content caches are separate from diagnostics.

2. Local and cloud translation

Chrome translation

When the browser supports the required capability and language packs are ready, the browser’s on-device model produces the translation. For this translation path, the extension does not send the text to the developer or a cloud-model endpoint. The browser may download language packs, subject to its provider’s practices. Fetching online captions can still contact the original website, so local translation does not mean that the entire extension is offline.

Cloud models and custom endpoints

When you select and start cloud translation, or enable automatic translation for a website, the extension sends text segments, source and target languages, item identifiers and necessary translation instructions to the selected endpoint. Video requests may include a small amount of adjacent caption text. Requests authenticate using the relevant API credential.

The current extension requests the selected service directly from your browser, without a translation proxy operated by us. The receiving service can obtain the request contents and ordinary connection information, such as your IP address, request time and client information. The extension does not include the original website’s login cookies or your entire browser history in model translation payloads.

The extension does not perform speech recognition for media without captions or upload audio/video streams for translation. Imported subtitle files are first parsed locally; their text may be sent if you subsequently use cloud translation. The original audio/video file is not uploaded by that action.

4. Storage and retention

  • API keys: personal keys are kept in extension session storage by default and are cleared when the browser or extension session ends or is reset. If you enable long-term local storage, the key remains in the browser’s local extension storage until you remove it or uninstall the extension. This storage is not an encrypted vault.
  • Other preferences: model, language, site and display settings are stored locally. The extension does not use Chrome sync storage to synchronize these records automatically.
  • Content caches: persistent caption and cloud-translation caches generally have a 14-day validity period and size or entry limits. Expired records are discarded during subsequent reads, writes or manual clearing, rather than by a deletion service that runs at the exact expiry time. Temporary page captions, imports and local translations are released when the page closes or resets.
  • Diagnostics and counters: these stay locally to show recent connection status and usage. Clearing translation caches does not automatically clear service settings, keys or usage records.
  • Exports: you control downloaded SRT, VTT and similar files. Closing or uninstalling the extension does not delete those downloads.

Some test releases include limited shared model credentials supplied by the developer. They are not personal user keys and do not promise unlimited free usage. Your saved personal key takes priority. Packaging credentials does not guarantee that an installation owner cannot extract them; the provider controls their actual scope and quota.

5. Why permissions are used

  • storage: stores the settings, credentials, caches and local status described above.
  • activeTab and scripting: run translation code packaged with the extension on pages you interact with or authorize.
  • contextMenus: provides right-click translation actions.
  • Video-platform and model-endpoint permissions: retrieve relevant captions and send the translation requests you select.
  • Optional HTTP/HTTPS access: supports other authorized websites, site-specific automatic translation and custom endpoints.

Site permission alone does not mean that every page is uploaded to a model. Translation depends on your actions and saved site rules. Video-site adapters may read or temporarily retain relevant caption responses already received by the page before translation starts.

6. Your controls and deletion options

  • Select Chrome translation, turn translation off, or disable automatic translation for a site to control future activity. Stopping or cancelling a request cannot guarantee withdrawal of data already received by a provider.
  • In service settings, select the option to delete the service’s saved key and save the settings to remove a personal key.
  • Deleting a custom model clears its configuration and saved key, not the remote model service. A revision marker without the endpoint, display name or key is retained to prevent stale results from returning.
  • Use the cloud-translation cache clear button and the video panel’s caption cache controls to clear the corresponding caches. Restoring the original webpage is a display action, not a cache deletion.
  • You can revoke site access or uninstall the extension in Chrome. Uninstallation clears local extension storage; downloaded files and records retained by providers require separate handling.

You may contact us below with privacy questions or data-related requests. Local records can be managed through these controls. Requests concerning records independently retained by a third party may also need to be addressed to that provider. This policy does not limit rights you have under applicable law.

7. Use limitations and security

Information handled by the extension is used for translation, preferences, caching, usage controls and necessary troubleshooting. We do not sell this information, use it for targeted advertising or credit evaluation, or use translation content to train the developer’s own models. The current extension has no advertising SDK, analytics SDK or telemetry service that sends translation content to the developer.

Remote model requests use HTTPS. User-configured loopback endpoints may use HTTP. Personal keys are not displayed in webpage translation overlays or extension diagnostics; bundled test credentials are used only in the extension background. Client software, local storage, packaged credentials and third-party processing cannot be described as risk-free.

8. This policy website and support channels

This is a static GitHub Pages website. It has no advertising, analytics scripts, forms or tracking cookies set by us, and it does not read extension settings or keys. GitHub states that Pages logs visitor IP addresses for security purposes; that hosting activity is subject to the GitHub Privacy Statement.

If you contact us through GitHub Issues or the QQ group, information you submit is handled by that platform and may be visible to other participants. Do not post API keys, account credentials or sensitive translation content in public issues or group messages. For a sensitive matter, first ask about an appropriate private contact method.

9. Policy changes

We will publish updates here and change the date. Material changes to functionality or data practices will be reflected in product information or appropriate notices, as applicable. The Chinese and English pages describe the same practices; contact the maintainer if you notice a discrepancy.

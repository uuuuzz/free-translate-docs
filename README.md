# Free Translate public documentation

Public privacy policy for the **免费翻译 / Free Translate** browser extension.

- 简体中文：https://uuuuzz.github.io/free-translate-docs/
- English: https://uuuuzz.github.io/free-translate-docs/en.html
- Contact: this repository's Issues and community QQ group **1130151486**.

This repository contains only public documentation and its stylesheet. It does not contain the extension source, installation archives, API credentials or private configuration.

GitHub Pages publishes the repository's default branch from `/`. The `.nojekyll` file enables plain static-file publishing. The pages do not use external fonts, scripts, forms or analytics.

Last policy update: **2026-10-29**.
